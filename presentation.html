SCENE 05 // 5:30–6:55 — FORMAL WORKLOAD PARTITIONING

Edge–Cloud Optimization: การแบ่งงานตามหลัก Pareto Frontier

Precedent: Chrome + Gemini Nano
Formal Workload Offloading Objective Function (MIT CSAIL Formulation)
$$\min_{\mathbf{a} \in \{0,1\}^N} \sum_{i=1}^N \Big( \underbrace{L_{\text{edge}}(x_i)(1-a_i) + (L_{\text{net}} + L_{\text{cloud}}(x_i))a_i}_{\text{Latency Bound } \le T_{\text{commit}}} + \lambda \cdot \underbrace{\text{Leakage}(x_i \cdot a_i)}_{\text{DP Budget } (\epsilon, \delta)} \Big)$$
EDGE SUBSYSTEM ($a_i = 0$)
  • Zero Network Round-Trip: $L_{\text{edge}} \approx 15\text{--}45\text{ms}$ ตัดสินใจทันก่อนเปิด Intent แบงก์
  • Zero PII Exfiltration: ข้อความดิบ $\mathcal{D}_{\text{raw}}$ ไม่หลุดออกจาก DRAM บนเครื่อง
  • Offline Degradation Grace: กรองภัยคุกคามพื้นฐานได้แม้ถูกตัดสัญญาณเครือข่าย
CLOUD SUBSYSTEM ($a_i = 1$)
  • Cross-Session Campaign Clustering: เชื่อมโยงสหสัมพันธ์ของข้อความระดับ $\mathcal{O}(10^6)$ ผู้ใช้
  • High-Capacity Verification: ประมวลผล GNN และ Heavy Discriminators เมื่อ Edge ไม่มั่นใจ
  • Continuous Threat Vector Synthesis: ดึง Signature ใหม่ลง Edge Cache สม่ำเสมอ
⚠️ Pareto Budgeting: ต้องวัด NPU Energy Consumption ($J/\text{inference}$), Thermal Throttling, และ Dynamic Quantization Tradeoffs
Bounded Execution Budget
